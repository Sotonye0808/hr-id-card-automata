# Project AI Context

Overview: HR ID Card Automata is a single-page Vite + React PWA that helps HR teams turn employee records and photos into printable ID cards. It is local-first (IndexedDB + localStorage), config-driven (JSON templates), and focused on simple batch export to PDF and DOCX with a live preview and light image editing.
